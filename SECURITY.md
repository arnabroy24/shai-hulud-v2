# Security policy

This is a deliberately vulnerable educational repository.

Do not report the documented `pull_request_target`/fork-head execution path as a new vulnerability. Please report any behavior that escapes the documented lab boundary, exposes a credential other than the lab canary, or affects another repository/account.

Do not place real credentials in issues, pull requests, workflow logs, or artifacts. If that occurs, immediately revoke the credential, delete the workflow run and artifact, and contact the repository owner privately.
